# Repository Overview — mithraa.SHI

*Verified against the code on 2026-10-24 (commit `77ea338`, branch `main`).*

## What this is

A **frontend-only, clickable prototype** of a film-production "studio OS". It shows the
idea of AI agents moving a film through 9 stages, with people signing a gate at each stage.

**Nothing in it is live.** There is no backend, database, AI model, login or network call.
Every number, agent, flag and approval comes from the static file `lib/data.ts`. The
"agents" are timers and a deterministic text heuristic (`components/studio/ideaEngine.ts`).
User actions (gate ticks, approvals, role switch) are kept in the browser's `localStorage`.

## Things that exist only as intent

- `lib/data.ts` header: *"In production these records live in the Project Brain (PostgreSQL +
  vector index + knowledge graph)"*. None of that exists in this repo.
- README mentions an **"Agentic Pipeline & Dashboard Blueprint"** document. It is not in the
  repo and must be requested from the previous team. Until then, the stage, agent and gate
  names in `lib/data.ts` are the only evidence of what it says, and they are not a spec.
- Per-agent "model spend caps" (`Agent.budgetK/spentK`) are display data only.

See [ARCHITECTURE.md](ARCHITECTURE.md) for how the pieces connect.
